# 호라이즌 마치 — 웹 프로토타입

Phaser 3(4) + TypeScript + Vite 기반 1차 프로토타입. 기획안([../기획안.md](../기획안.md)) §5.3 "청옥 등장 이벤트 — 북소리 리듬 챌린지" 메커닉을 검증하기 위한 수직 슬라이스입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속. 개발 서버에서는 `http://localhost:5173/?time=night`로
거리 씬의 밤 조명을 미리 볼 수 있습니다(대본상 밤 장면용 팔레트 확인용, 프로덕션 빌드에선 무시됨).

## 조작

**모바일 / 터치** — 화면에 조이스틱 같은 건 없습니다. 눌러서 움직입니다.
- 화면(길)을 **탭**하면 그 자리로 걸어가고, **누른 채 끌면** 손가락을 따라갑니다(보이지 않는 조이스틱처럼).
  길 위쪽을 탭하면 안쪽으로, 아래쪽을 탭하면 카메라 쪽으로 깊이도 함께 움직입니다.
- **NPC / 도리이 문을 탭**하면 그쪽으로 걸어가서 도착하는 즉시 대화·이동이 시작됩니다.
  가까이 가면 뜨는 "말 걸기" 알약을 탭해도 됩니다.
- 대화창은 **어디든 탭**하면 다음 줄(타이핑 중이면 즉시 완료), 선택지는 큰 버튼을 탭.
- 흥정 미니게임은 **화면 아무 곳이나 탭**해서 멈춤, 도주 QTE는 패널 아래 **큰 버튼 3개**(◀ / 점프 / ▶),
  청옥 북소리 회피는 **화면 왼쪽 절반 / 오른쪽 절반을 탭**.
- 우상단 ☰ 에서 데모 트리거(청옥 등장, 도주 QTE, 다음 장소)를 열 수 있습니다(키보드의 E / Q / C 대응).

**키보드**
- `←` / `→` : 이동
- `↑` / `↓` : **깊이(depth) 이동 — 진짜 2.5D**. 위로 걸으면 화면 안쪽으로 멀어지며 작아지고
  NPC들 뒤로, 아래로 걸으면 카메라 쪽으로 가까워지며 커지고 NPC들 앞으로 렌더링됩니다
- `Space` : (아키코 근처에서) 대화 시작 / 대사 다음으로 넘기기·타이핑 즉시 완료
- `1` / `2` / `3` : 대화 선택지 고르기
- `E` : 청옥 등장 트리거 (테스트용 — 실제 게임에서는 스토리 진행에 따라 자동 발동)
- 청옥이 북을 칠 때 화면에 뜨는 `◀◀ 피해!` / `피해! ▶▶` 텔레그래프를 보고 반대 방향 키를 타이밍에 맞춰 입력 → Perfect / Good / Miss 판정
- `Q` : 헌병 도주 QTE 트리거 (테스트용). 화면에 뜨는 `←`/`→`/`SPACE` 프롬프트를 줄어드는 타이머 안에 맞춰 입력
- 맵 오른쪽 끝의 "다음 장소 →" 문까지 걸어가서 `Space` : Ch.5 "입영" 장면(다음 맵)으로 이동.
  해당 장면에서는 `B`로 다시 오사카 거리로 복귀 (디버그용 `C` 키도 동일하게 동작)

## 반응형 레이아웃 (모바일 · 세로/가로)

- **무대는 높이 540으로 고정**하고, 기기에 따라 *그 주변을 얼마나 보여주는지*만 바뀝니다(`src/render/layout.ts`).
  가로/데스크톱은 높이 540에 너비가 화면비를 따라가고(16:9 → 960, 폰 가로 → 최대 1170),
  **세로는 너비 480에 높이가 늘어나** 남는 높이만큼 하늘과 길·부두가 더 보입니다(UI가 사는 곳).
- 모든 모듈이 import 시점이 아니라 **호출 시점에** `layout`을 읽기 때문에, 폰을 돌리거나 창 크기가 크게 바뀌면
  `main.ts`가 새 레이아웃을 적용하고 현재 씬을 **다시 시작**합니다(거리 씬은 서 있던 x 위치를 이어받음,
  `relayoutData()`). 주소창이 접히는 정도의 작은 변화는 Phaser FIT 레터박스에 맡깁니다.
- 레이어는 `layout`별로 캐시 키가 달라 회전 후에도 올바른 크기로 다시 그려지고, 이전 레이아웃의 텍스처는 정리합니다.
- UI 글자·터치 대상은 `uiScale`(= 화면이 축소된 만큼 키움)로 CSS 기준 ~13–14px / 44px 이상을 유지합니다.
- `index.html`/`style.css`: `viewport-fit=cover` + 노치·홈 인디케이터 safe-area 회피, `100dvh`, 오버스크롤/풀투리프레시·
  더블탭 줌·길게누르기 메뉴·텍스트 선택 차단.

## 아트 & 렌더링

- **캐릭터**: `src/assets/characters/`의 6개 PNG는 기획안 캐릭터 디자인 시트(§3, 반실사 톤)에서
  잘라낸 컷아웃입니다. `tools/extract_characters.py`로 재생성할 수 있습니다
  (`python3 tools/extract_characters.py <시트 이미지> <출력 폴더>`, Pillow·scipy 필요). 종이 배경을
  행 단위로 추정해 제거하고, 팔·다리 사이의 종이 구멍과 옆 인물 조각을 지우고, 가장자리만 부드러운
  알파 + 종이색 번짐 제거(디컨태미네이션)를 한 뒤 LANCZOS로 440px 높이에 맞춥니다. 원본 시트 자체가
  인물당 약 500px이라 그 이상의 디테일은 없습니다 — 더 선명한 그림은 고해상도 원화가 있어야 합니다.
- **2× 렌더링** (`src/render/HiDpi.ts`): 이전엔 960×540 캔버스를 CSS로 늘리고 `pixelated`까지 걸려
  있어 캐릭터가 깨져 보였습니다. 지금은 캔버스를 1920×1080으로 그리고 카메라를 좌상단 기준 2배 줌해서,
  게임 코드는 그대로 960×540 논리 좌표를 쓰면서 스프라이트·도형·텍스트 모두 레티나 밀도로 렌더링됩니다.
  카메라 추적은 `followCameraX()`가 담당(Phaser 기본 follow/bounds는 중앙 원점 전제라 사용 안 함).
  세로 화면에서는 카메라 y를 `layout.camY`만큼 올려 무대가 화면 아래쪽 2/3에 앉고 위는 하늘이 됩니다.
- **배경** (`src/scenery/StreetBackdrop.ts`, `HarborBackdrop.ts`, 공용 `paint/`): 전부 Canvas 2D로
  2× 해상도에 그린 회화풍 레이어입니다. 오사카 거리는 하늘·구름·햇살 / 원경 산 / 안개 낀 원경 도시와
  통천각풍 철탑·공장 굴뚝 / 기와지붕 마치야(노렌, 격자창, 간판, 초롱, 화분·자전거 같은 소품) / 전신주와
  처진 전선·참새 / 조약돌 도로와 전차 선로까지 6개 패럴랙스 층. Ch.5 항구는 아침 해가 반짝이는 바다,
  깃발 단 수송선과 연기 나는 굴뚝, 크레인, 나무 부두, 갈매기, 물안개. 레이어는 시드 고정 난수로 그려
  텍스처 캐시되므로 씬을 다시 들어와도 다시 그리지 않습니다.
- **시간대 = 대본 기준**: 기본은 낮, 대본 지문이 밤인 장면에만 밤을 씁니다. 거리(아키코 흥정, 대본
  p.3 "1940년대. 어느 집 앞")는 낮, 입영 항구(p.12 "아침. 항구")는 아침. 밤 팔레트(달·별·불 켜진
  창·초롱·가로등, 캐릭터 달빛 틴트)는 가네무라 도주(p.9)·밤길(p.11) 같은 밤 장면용으로 준비돼 있습니다.

## 구현된 것

- **맵 기반 자유 탐험 구조**: "한 맵 = 한 에피소드, 맵 끝에서 다음 맵으로" 구조로 바뀌었습니다.
  - 플레이어가 `Space`로 말 걸 수 있는 대상이 아키코 하나였던 걸, 제네릭 `Interactable` 목록
    (`PrologueScene.interactables`)으로 일반화해서 가네무라·강성·순주도 각자 짧은 한 줄 대사를
    갖고(`src/dialogue/data/companionLines.ts`) 자유롭게 말 걸 수 있습니다. 가장 가까운 대상만
    프롬프트가 뜨고 자동으로 전환됩니다.
  - NPC들은 더 이상 가만히 서 있지 않고, 2~4초마다 홈 포지션 근처(±90px)를 랜덤하게 오가며
    배회합니다(`scheduleWander()`). 대화 중이거나 청옥 체이스 중에는 멈춥니다.
  - 맵 오른쪽 끝에 실제로 걸어서 통과하는 주홍색 도리이(행선지 현판 포함)를 두고, 거기 도달해
    `Space`를 누르면 Ch.5 씬으로 전환됩니다 — 디버그 키(`C`)가 아니라 맵 안의 실제 오브젝트를 통한
    장소 이동입니다.
  - 참고로 Gather.town류(sansatemple.com 등) 멀티플레이어 실시간 소셜 공간과는 장르가 다릅니다
    (우리는 싱글플레이 내러티브 + 미니게임 중심). 다만 그 UX의 핵심 아이디어 — "한 맵을 자유롭게
    돌아다니다 가장자리에서 다음 공간으로 넘어간다" — 는 그대로 가져와 적용했습니다.
- **캐릭터 애니메이션(프로시저럴)**: 정지 일러스트 한 장뿐이라 실제 프레임 애니메이션은 없지만,
  `PrologueScene.updatePlayerAnimation()`에서 걸을 때 스쿼시&스트레치 바운스 + 좌우 기울임(걸음걸이
  스웨이)을 매 프레임 사인파로 합성하고, 약 260ms마다 발밑에 옅은 먼지 이펙트를 띄웁니다. 멈춰 있을
  땐 더 느리고 작은 "숨쉬기" 펄스로 전환. NPC·아키코 등 가만히 서 있는 캐릭터들도 `addIdleBreathing()`
  으로 같은 종류의 느린 스케일 펄스를 돌려 화면이 얼어붙어 보이지 않게 함(Ch.5 씬도 동일 적용).
- **진짜 2.5D 깊이 이동**: 플레이어가 ↑/↓로 지면의 얕은 "깊이 밴드"(`DEPTH_BAND_TOP`~`DEPTH_BAND_BOTTOM`,
  `PrologueScene.ts`) 안에서 움직일 수 있고, 그에 따라 캐릭터 스케일이 선형 보간되며(멀수록 작게,
  가까울수록 크게) Phaser depth를 y값에 맞춰 매 프레임 갱신해 NPC와의 앞뒤 가림(z-order)이 실제로
  일어남. 단순 패럴랙스 배경(아래 항목)과는 별개로, 캐릭터 자체가 깊이축을 갖는 부분이 핵심.
- **통일된 UI 패널** (`src/ui/Panel.ts`): 대화창·흥정·도주 QTE가 전부 같은 둥근 모서리 +
  블러 드롭섀도 + 은은한 광택 패널을 공유(2× 해상도로 그려 선명함). 이름표·HUD 텍스트는 밝은 낮
  배경에서도 읽히도록 어두운 외곽선(`src/ui/textStyle.ts`)을 둘렀습니다.
- **Ch.5 "입영" 장면** (`src/scenes/Ch5EnlistmentScene.ts`): 기획안 §4 Ch.5를 각색한 별도 Phaser
  씬. 아침 항구 배경으로 바꾸고, 대본 pp.9-13의 혼인신고·입영통지서·반자이 장면을
  각색한 대화(`src/dialogue/data/enlistment.ts`)를 자동 재생. "반자이를 외칠 것인가 / 거부할
  것인가" 선택은 기획안에 적어둔 대로 결말에는 영향을 주지 않는 감정적 분기로 구현. `PrologueScene`
  에서 `C`로 진입, `B`로 복귀하는 간단한 씬 전환도 포함.
- 플레이어 이동 + 카메라 추적
- 청옥 등장 시 NPC 산개(scatter) 연출
- 북소리 타이밍 기반 리듬 챌린지(경고 텔레그래프 → 입력 판정 → Perfect/Good/Miss)
- Miss 시 카툰풍 넉백(포물선 + 회전 트윈) + 카메라 셰이크
- 전 과정 "질 수 없는" 설계 — 실패해도 스토리/루프는 계속 진행
- **JSON 기반 분기 대화 시스템** (`src/dialogue/`): 재사용 가능한 `DialogueBox` 컴포넌트 +
  대본 pp.3-4 설탕 흥정 장면을 각색한 샘플 트리(`src/dialogue/data/akikoSugar.ts`).
  타자기 효과, 선택지 분기, 대화 중 플레이어 이동 잠금을 지원.
  새 장면은 같은 `DialogueTree` 포맷의 데이터 파일만 추가하면 코드 수정 없이 재생 가능.
- **흥정 미니게임** (`src/minigames/PriceNegotiation.ts`): 좌우로 스윕하는 포인터를 Space로 멈춰
  가격을 정하는 타이밍 바 방식. 중앙 GREAT존(45~55전)/주변 GOOD존(35~65전)/그 밖 POOR로 판정하고,
  결과에 따라 대화 트리의 `deal_great` / `deal_good` / `deal_poor` 분기로 자연스럽게 복귀해
  대화가 계속 이어짐. 아키코와의 대화 중 "있어요, 얼마면 좋을지 흥정해봐요!" 대사 직후 자동 발동.
- **헌병 도주 QTE** (`src/minigames/EscapeQTE.ts`): 기획안 §4 Ch.3 "균열"의 암거래 단속 도주 장면을
  구현한 반응속도형 QTE. `←`/`→`/`SPACE` 중 무작위 프롬프트가 4연속으로 뜨고, 매번 짧아지는
  타이머 안에 맞는 키를 눌러야 함. 맞히면 "헌병과의 거리" 트랙이 안전 쪽으로, 틀리거나 시간 초과면
  위험 쪽으로 이동. 실패 횟수에 따라 결과 대사만 달라질 뿐(완전히 따돌림 vs 아슬아슬하게 도망)
  게임 진행은 절대 막히지 않는 "질 수 없는" 설계.
