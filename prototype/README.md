# 호라이즌 마치 — 웹 프로토타입

Phaser 4 + TypeScript + Vite. 대본(『호라이즌 마치』)을 **장면 순서대로** 따라가는 10개 장짜리 스토리 어드벤처입니다.
각 장에는 대사 진행 + 미니게임이 있고, 가네무라 편에서는 헌병을 피해 달리는 러너가 나옵니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc + vite build → dist/
```

## 장 구성 (src/game/story/)

| 장 | 제목 | 장면 / 미니게임 |
|---|---|---|
| 1 | 노인들의 부두 (1990년대) | 야스다·가네무라 노인 → **실랑이(탭 연타)**로 싸움 자세 → 시대 전환 |
| 2 | 대판이다, 대판! (1930년대 후반) | 배 위 → 부두에서 청옥 등장 → **북 리듬 점프** → 오사카 질주 |
| 3 | 오십 전 아저씨 (1940년대) | 야스다–아키코 → **가격 흥정(타이밍 바)** → 아키코가 다가오는 **선택지(가만히/피하기)** |
| 4 | 밥은 먹고 가! | 날아오는 밥그릇을 **점프로 피하기** → 순주 등장 |
| 5 | 괴물과 결혼?! | 가네무라·강성과 대화 → 청옥 재등장 → **분노의 북** |
| 6 | 닭꼬끼 아저씨 | 아키코·마사요·메구미 등장 → 선택지 → **크게 화답(연타)** |
| 7 | 술 한잔 | 청옥의 집 → **술 따르기(타이밍 바)** → 청옥의 포옹 |
| 8 | 오늘 밤, 도망쳐야 돼 | 가네무라의 위기 → **헌병 피해 달리기(러너, 점프)** |
| 9 | 야스다, 입대 | 아키코의 집 → 밤길 걷기(직접 조작) + **반지 던지기** → 항구 작별(**"살아서 돌아와!" 연타**) |
| 10 | 종전, 그리고 만세 | 종전 방송 → 청옥 추격 → **모두 함께 환호(연타)**, 크레딧 |

장면은 `src/game/story/part1.ts`, `part2.ts` 의 비동기 스크립트(`async play(s)`)로 정의됩니다.
`ChapterScene`(src/game/ChapterScene.ts)이 `put / enter / talk / choose / goTo / drum / timing / mash / card / sepia / confetti …` 같은 연출 API를 제공합니다.

## 조작

- **모바일(세로/가로 모두)**: 화면 어디든 **탭** = 대사 넘기기 · 미니게임 입력 · 이동. 직접 조작 구간에서는
  길을 탭하면 그곳으로 걸어가고(보이지 않는 조이스틱), **점프 버튼**/캐릭터 탭으로 점프. 우상단 ☰ 에서 장 이동·장면 건너뛰기.
  가로로 돌리면 더 넓게 보이며, 타이틀의 **전체화면 · 가로 모드** 버튼(지원 브라우저)으로 가로 고정 시도.
- **키보드**: `Space` 대사 넘기기/미니게임 입력/점프, `1·2·3` 선택지, `←→`/`A D` 이동(직접 조작 구간), `↑` 점프(러너 포함).
- 진행 상황은 브라우저(localStorage)에 저장되어 타이틀에서 "이어하기"로 재개합니다.

## 반응형 레이아웃

무대 높이 540 고정. 가로 화면은 창 비율대로 넓게, 세로 화면은 폭 480에 위·아래로 하늘/길을 더 보여 줍니다
(`src/render/layout.ts`). 2× 캔버스 + 줌 카메라로 선명하게 렌더링하고, 회전/큰 리사이즈 시 현재 장면을 다시 시작합니다.
노치/홈바 안전영역(`env(safe-area-inset-*)`)은 UI에서만 피합니다.
