# 호라이즌 마치 (Horizon March)

연극 <호라이즌 마치>(2026 <프로젝트 호라이즌> 한일연극제, 작 김철의 / 연출 권민경)를 원작으로 한
2.5D 내러티브 어드벤처 웹게임입니다. 1930~40년대 오사카의 제주 출신 청년들과 일본인들의 이야기를
대화·미니게임으로 대본 장면 순서대로 따라갑니다. 10개 장(노인의 부두 → 종전과 만세), 모바일 세로/가로 모두 지원.
